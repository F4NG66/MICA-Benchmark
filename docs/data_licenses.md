# Data origins and terms

- Experimental reference mmCIFs were downloaded from wwPDB; consult https://www.wwpdb.org/about/usage-policies. Original compressed references and their byte hashes are retained.
- Original density maps are EMDB archive files; source records and dates are in `targets.json`. Consult https://www.ebi.ac.uk/emdb/documentation/policies. Canonical maps differ only by lossless voxel-axis permutation and origin translation; map_transform.json gives the transform. No resampling or density fitting was used for normalization.
- `data/af3/selected` contains AlphaFold 3 predicted outputs, and MICA/EMProt/EModelX final models use these predictions. These files are distributed subject to the included AlphaFold 3 Output Terms of Use and notice. Modifications include domain extraction/docking, density-guided rebuilding, and (for MICA/EModelX) real-space refinement; final coordinates are translated back to the original deposited frame. No AF3 weights are included. Cite Abramson et al., Nature (2024), https://doi.org/10.1038/s41586-024-07487-w.
- `data/af3/processed` contains exact native AF3 job input JSONs with sequence/MSA/template data. Their source sequences/templates originate from public biological archives. No license over upstream database content is superseded by this release. These processed inputs contain no AF3 model parameters.
- Other model outputs were generated with ModelAngelo/CryoAtom/CryoAtom2; cite their papers listed in the code package. No new blanket CC0/CC-BY license is claimed over this mixed release. Metadata/results and original benchmark scripts are provided separately from third-party source and outputs.
- Third-party MICA source excerpts retain their MIT copyright/license under `third_party/MICA/LICENSE`. The historical source path prefix is replaced with `/ORIGINAL_BENCHMARK_ROOT` in public provenance for portability; actual data files and inference processed JSONs retain their original byte hashes.
